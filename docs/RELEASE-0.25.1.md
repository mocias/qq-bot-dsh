# 0.25.1：工作区目录自动补建

修复已保存 DSH 会话的工作区被手动删除后，启动和后续执行持续报 `working-directory: directory does not exist` 的问题。

启动、普通消息、后台记忆整合及会话替换在使用工作区前检查目录。受管的 `runtime/workspaces` 目录缺失时，按已保存的原路径补建空目录，继续原 DSH 会话；不会为目录缺失单独创建新会话，也不会恢复用户删除的工作区文件。配置和独立记忆库保持原状。

已有的外部工作区目录继续兼容，但缺失的外部路径不自动创建。受管路径被文件、符号链接或目录联接占用时停止提交，保留原有内容并报告错误。无法创建目录属于提交前失败，不按未知模型执行重放。

回归使用隔离临时资料与模拟 DSH，覆盖旧路径复用、整个工作区树删除、消息准备期间删除、后台整理、手动会话替换、配置与记忆回执保留，以及路径占用检查。真实模型和 QQ 发送不作为自动验收步骤。
