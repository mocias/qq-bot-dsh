# QQ 功能迁移 · 0.4

运行方式仍是独立 Node 服务接入 DSH，不需要把 QQ 服务安装为 DSH 插件。DSH 负责模型和工具循环。

## 沿用与适配

| 功能 | 独立服务行为 | 复用与适配 |
| --- | --- | --- |
| 图片 | 私聊及被 @ 的群聊读取图片，实际像素作为 DSH 附件；可向当前聊天发图片 | 复用原图片格式检测、群工作区保护；公网下载、大小限制、拒绝链接/越界目录 |
| 合并转发 | 展开转发文字及嵌套图片/语音；按当前私聊/群聊发送合并节点 | 沿用 OneBot 节点格式，最多 4 层、100 段输入；输出最多 50 个文本节点 |
| 语音接收 | NapCat `get_record` 转 WAV，优先读取其返回数据，再由本地 Whisper 识别 | 复用现有模型；仅返回本地路径的实现需要授权媒体缓存目录 |
| 语音发送 | 私聊合成短语音；按自动/文字/语音偏好与安静时段决定，群聊暂不自动合成 | 复用原语音长度、技术内容与安静时段规则，现阶段 Windows TTS；准备失败回退文字，发送结果未知不重试 |
| 主动回忆 | 只向最近真实聊天的允许联系人自然提起有效记忆 | 直接复用原 RecallSchedule 与邀请正文；候选取当前有效页面，避开已忘记的日志 |
| 定时主动消息 | 私聊回忆及群聊定时参与，随机间隔、活动时段、每日上限 | 群聊需 90 分钟内有真实成员活动且存在会话；没有切入点保持安静 |

两种主动消息默认关闭，可在“连接与配置”中分别开启。默认间隔 30–120 分钟，北京时间 09:00–23:00，每日最多尝试 3 次。新用户输入会重新计时；会话轮换与服务重启保留按聊天身份记录的额度。新消息到达时取消尚未发送的主动回复，等待 DSH 确认取消后处理用户消息。普通文字插话和多媒体排队分别处理，多媒体不会被降成只有占位符的 steer。

群聊两次发送间隔、每小时发送额度沿用原规则，0 表示不限。为防止超时后重放，本版在尝试前占用主动额度，失败/取消也计数，群发送结果未知也占额度；这比原群插件只计成功发送更保守。默认两个群限流值均为 0，可在面板调整。

这次迁移的是原有主动搭话机制，不包含通用 cron/提醒任务编辑器、群聊无 @ 的持续旁听、人设编辑、桌面自主行动或电话通话。主动消息本身不得执行桌面或外部动作，DSH 工具权限仍须在预设中限制。MiMo 云语音适配源码仍保留在原语音模块，尚未接入独立面板。

## 模型输出与媒体边界

保持原有 `{"reply":"正文","memory":[]}`，可选增加一种 `qq` 输出：

```json
{"reply":"图片说明","memory":[],"qq":{"images":["当前工作区相对图片路径"]}}
```

```json
{"reply":"","memory":[],"qq":{"voice":"要朗读的短句"}}
```

```json
{"reply":"","memory":[],"qq":{"forward":[{"name":"助手","content":"第一条内容"}]}}
```

不能指定其他收件人。发图仅允许当前工作区、当前聊天媒体归档或公网 HTTP(S) 地址。工作区下 `.memory`、`.runtime` 等受保护目录禁止发送。单图/音频最大 8 MiB，输入最多 6 图/24 MiB，发送最多 9 图；转发节点正文限 500 字。图片理解取决于所选模型是否支持视觉。

媒体位于私有 `.runtime/media/<聊天哈希>/`，按 24 小时、每聊天 200 文件/256 MiB 清理，不上传 GitHub。DSH 自身保存的会话附件不受此清理影响。音频原文只在本机模型处理；识别后的文字及图片会交给配置中的 DSH/模型服务处理。

## 避免 QQ 重复登录

先单独安装官方 NapCat Framework，在面板保存 QQ.exe 路径与 Framework 目录。然后点击“打开桌面 QQ”，或运行 `npm run start:desktop-qq`：

1. 正确账号的 OneBot 已在线：直接复用，不启动新进程。
2. QQ/加载器已运行但接口不可用：提示检查连接；不强退、不重复登录。
3. 没有 QQ 实例：校验官方加载器文件后启动桌面模式，登录由 QQ 窗口完成。

同一账号的桌面窗口和机器人共用该实例。不要另外启动后台 Shell。启动器有互斥锁，异常遗留锁需在检查进程后人工处理。本保护针对重复启动造成的账号占用，不能保证消除 QQ 自身的网络、风控或登录验证问题。

## 验证范围

见 `VALIDATION.md`。模拟测试覆盖媒体解析、图片真实附件、发送未知不重试、主动额度持久化、新消息取消、QQ 登录复用/冲突拦截。真实本地 TTS/Whisper 和 DSH 合成图片测试通过；真实 QQ 多媒体收发及长时定时运行仍需要用户逐项验收。
