# 0.26.0-rc.4 · 工作区命名简化

按用户要求调整新建 DSH 工作区的命名：目录名只保留创建日期与人格卡名称，不再带聊天类型和对象号码；聊天类型与号码保留在同一工作区内的 DSH 会话标题中。功能与权限没有变化。

## 命名规则

| | 旧 | 新 |
| --- | --- | --- |
| 工作区目录 | `2026-10-22-群聊-100000002-知遥` | `2026-10-22-知遥` |
| 工作区上级目录 | `workspaces/<机器人账号>/<群聊或私聊>/` | `workspaces/<机器人账号>/` |
| 工作区内的会话标题 | `2026-10-22-群聊-100000002-知遥-1` | 不变 |

- 目录名仍是“北京时间创建日期-人格卡名称”，人格名称非法字符替换、最多 40 个 Unicode 字符、默认人格显示“默认人格”的规则不变。
- 会话标题继续包含日期、聊天类型、对象号码、人格名称和按聊天递增的编号，用于区分同一工作区内的多轮会话。
- 同一机器人账号下，同一个人格被多个聊天使用时会得到相同目录名，按既有规则追加 `-工作区N` 区分；不同机器人账号仍在各自父目录下，不会互相覆盖。
- 已存在的工作区不改名、不移动、不重建；本版只影响此后新分配的工作区。修改人格名称同样不会移动旧目录，轮换仍复用原工作区。
- 工作区内的记忆、权限、模型与提示词配置路径不变；记忆库仍按“聊天+人格”的哈希目录隔离，与会话标题无关。
