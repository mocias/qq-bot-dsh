# 0.18.3 回合与工具生命周期

修复真实运行中的故障：整理回合等待模型重试超过180秒后，桥接先释放了6个记忆工具，DSH仍继续调用，出现unknown tool。模型请求自身的超时和Windows沙箱ACL错误不在本次修改范围。

- 空闲/启动记忆整理和上线招呼使用 `lifecycleBound`，等待DSH回合明确结束，不再使用180秒总时限。连续聊天原有15分钟窗口不变；模型请求、重试策略、Windows权限均未改动。
- 桥接每30秒通过现有原生release控制入口续期一次。插件240秒限制改为可续期的失联租约，正常长回合可持续保有工具。续期要求匹配session、runId及本轮私有token，失效授权不能恢复。
- 正常完成在观察到回合结束后释放；记忆提交仍由宿主工具校验并持久化回执，未提交不能进入招呼/正常回复。明确停止先撤销写入授权并请求DSH Agent取消，等结束确认后卸载工具。
- 租约过期、宿主回调断开或取消请求时，插件将回合标记失效并请求Agent取消。工具名称继续存在，调用返回明确的失效错误；未确认结束前不直接卸载工具。收到对应turn/end或确认Agent空闲后清理。
- 桥接断线后通过插件控制状态确认退出。确认等待有界；失败则将exitUnconfirmed保存于私有会话状态，当前聊天后续输入继续落盘排队，不创建替代会话。重启也保留此状态，恢复前检查旧Agent是否结束。用于确认的能力token不进入UI、模型上下文或公开日志。
- 复用现有RPC使稳定加载器无需重新注册远程方法；仍要求服务与插件统一版本和构建。主动卸载插件/退出DSH属于宿主生命周期，不属于可持续续期保证。

验证使用模拟DSH、OneBot、临时记忆库以及模拟时钟：推进6分钟并通过真实客户端续期/工具回调完成digest；租约丢失、提前release、失效后续期、错误能力token、延迟取消确认、断线取消未确认、禁止创建替代会话和重启后保留队列均有回归。未用真实模型的长回合冒充模拟测试。
