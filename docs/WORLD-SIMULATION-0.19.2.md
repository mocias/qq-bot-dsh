# 真实世界模拟 · 0.19.2

每个已启动并完成启动整理/招呼的原生聊天，独立计算距上次投递给 DSH 的消息或模拟提示的 60 秒间隔。不是整分钟日历任务，不通过额外的 DSH 会话或 Codex 自动任务运行。

- 正常执行输入和等待收到的新消息都附带 `真实世界模拟` 字段：北京时间、结合人设/已确认行动/上下文的角色状态推演。不能把推演当真实经历写入事实记忆，也不要求向 QQ 报告。
- `qq_wait_for_messages` 可在提醒到期时提前返回 `reason: world-simulation` 及该字段。每次短等待超时不重置提醒；新消息投递则重计 60 秒。忙碌期间到期的多次提醒合并为一次，等下一次等待时处理。
- 普通聊天只提供等待，不再提供 `qq_no_reply`；后台主动任务仍保留该沉默出口。普通聊天无总时长/轮数限制。单次等待上限仍为300秒，明确停止或连接关闭照常退出。
- 若模型自行结束且聊天空闲，现有 tick 调度在原聊天串行队列提交一次内部提示；等待子任务的父 Agent 则经现有绑定恢复。整理、未确认退出、待处理消息优先，不并行启动第二个模型回合。
- 内部提醒没有 QQ 消息来源或未读序号，不写进 QQ 历史，不充当人物证据，不消费历史未读，不自行创建聊天会话。已有完整人设、工具/skills 和记忆上下文沿用原通道。
- 该版本不改变允许名单、群聊/私聊开关、真实发送限额、启动历史边界、记忆存储及会话轮换规则。停止的聊天不运行提醒。

验证覆盖相对计时、新消息重计时、忙碌合并、停止、整理互斥、不同聊天独立以及内部提示不污染消息/记忆。真实模型是否自然表达仍需真实对话观察。
