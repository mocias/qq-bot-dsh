# 0.20 人格卡

同一个好友或群可以创建多张人格卡，每次启用一张。人格卡属于所选机器人账号下的具体聊天，不会自动复制到其他群、好友或账号。

## 使用

在“人设与记忆”选择聊天对象，再选择“人格卡”。原“聊天类型”选择器移除，对象列表同时标明好友和群。

- “新建人格卡”创建空白人格，现有资料保留为“默认人格”。创建后编辑并保存人设。
- 选择卡片只预览其资料，不改变聊天使用的人格。“当前使用”和“正在预览”分别显示。
- 停止对应类型的 QQ 接收并等待旧任务结束，再点击“确定配置”。之后手动启动接收。切换不会自动发消息或扩大接收范围。
- 切回旧卡恢复其资料及会话映射。启动流程仍按已有规则整理历史并生成上线招呼，旧积压消息不补答。
- 重置“此聊天全部记忆”涉及该聊天所有人格，保持原有本地备份流程；卡片名称和选择保留。

## 隔离与兼容

人格注册表保存在运行目录的 `persona-cards.private.json`，采用版本检查和原子替换。卡片具有稳定 ID，名称仅用于展示。默认人格完全沿用升级前的目录、会话范围与记忆数据，无需搬迁或复制。

新增人格按聊天标识和人格 ID 派生独立存储范围：SOUL/BOOTSTRAP、长期记忆与修订历史、语音配置、知识笔记、消息索引、聊天窗口，以及 DSH 会话和工作区。聊天目标、允许名单、权限、DSH 预设、发送频率和主动发言额度仍按聊天配置，不因切换而扩大权限或重置群发送额度。

路由中的 QQ 目标保持原格式；人格不改变收件人。后台整理只读取当前人格的会话来源，旧人格的提醒不再投递。未确认退出、活动任务、启动发送结果未知和过期配置都会阻止切换。管理写入显式带人格 ID，多卡聊天拒绝未指定人格的旧页面写入。

## 验证边界

使用隔离数据验证默认路径保留、独立编辑、A→B→A 会话与工作区恢复、重启保留选择、跨聊天拒绝、旧人格提醒拦截、忙碌/未知退出/过期配置拒绝、重置备份全部卡片，以及面板创建—预览—保存—确认流程。真实 QQ 发消息与真实模型的角色表达不属于这次验证。
