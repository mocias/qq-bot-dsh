# 音色设计与人设语音预设（0.10）

## 三种 MiMo 合成模式

根据 [MiMo 合成指南](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5) 和 [TTS API](https://mimo.mi.com/docs/zh-CN/api/audio/tts) 核对：

- **音色设计**：模型 `mimo-v2.5-tts-voicedesign`，必填文字描述放入 user 消息；不上传录音，不传 `audio.voice`。语气提示附加在描述后。明确发送 `optimize_text_preview:false`，保持助手原本要说的正文。
- **音色克隆**：模型 `mimo-v2.5-tts-voiceclone`，必须选有效参考录音，`audio.voice` 使用音频数据。
- **预置音色**：保留 `mimo-v2.5-tts` 与已有音色列表，兼容旧配置。

三种模式都把目标文字放在 assistant 消息中，使用非流式 WAV 并校验返回音频。旧配置不自动切换模式，已有密钥、录音和默认语音配置保持原样。

## 操作流程

1. 在“语音与通话”选择服务和音色方式。设计模式只填写音色描述；克隆模式选择参考录音。
2. 填写预设名称，点击“将下方设置另存为预设”。更新已有预设时先选择预设，再点击“更新所选预设”。预设保存服务模式、本地声音/识别模型、MiMo 模式/描述/录音编号/语气/识别语言；不保存 API Key。
3. 下方试听使用当前选中的已保存预设；没有选择预设时使用全局默认。修改但没有保存的表单内容不会用于试听。保存为全局默认不会自动更新命名预设。
4. 在“人设与记忆”选择具体好友或群，选择语音预设，点击“保存此人设的语音选择”。此版本的人设仍按机器人账号＋聊天类型＋号码隔离，并未增加同一聊天内的多人设切换。

人设保存的是独立副本：公共预设之后更新或删除，都不会自动改变已绑定人设。要采用新版，需要重新选择该预设并保存。选择“沿用全局默认”并保存则移除副本。QQ 收到语音和合成回复均使用该聊天解析出的语音配置，发送权限、安静时段及发送范围继续由聊天域策略控制，选择音色不打开权限。

API Key 始终从本机全局配置取得。预设可以先建好，但实际调用 MiMo 需要有效的共享密钥；界面首次输入密钥时应先保存默认配置与密钥，再保存预设。清除共享密钥后，人设中 MiMo 的配置副本保留，但不能再调用 MiMo；不会自动选择其他服务。

## 数据与删除

预设库：私有运行目录的 `voice-profiles.private.json`。人设副本：对应记忆库 `.runtime/persona-voice.json`。两者均排除上传，密钥不写入副本、预设或系统日志。

预设可删除和恢复。删除不影响已经保存的人设副本；删除录音前同时检查全局配置、活动预设及所有人设副本的引用。若恢复已删除的克隆预设，其参考录音也必须可用。

人设语音选择属于该人设记忆管理范围，重置此聊天全部记忆时随记忆一起归档；公共预设库、录音和共享密钥保留。不同聊天之间不能自动复制语音选择。写接口要求认证、停止接收并等待任务结束，预设及人设选择带版本校验，避免覆盖其他面板的更新。

## 验证边界

测试使用模拟 MiMo 返回的 WAV，覆盖设计/克隆请求参数、无录音设计、未填描述拒绝、独立副本及账号/好友/群隔离、更新与删除后副本保留、录音引用保护、重置范围，以及 QQ 媒体发送链路按聊天选用不同模型。

浏览器测试使用虚构账号和模拟接口，验证预设创建、无录音设计试听、人设绑定、其他群保持默认及刷新持久化。未调用真实 MiMo、未发送真实 QQ 消息，不能宣称真实音质或音色稳定性已验收。
