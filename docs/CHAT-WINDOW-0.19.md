# 0.19 聊天窗口与独立整理

参考 qq-bridge 二代仿真 `src/bridge.js` 的【反AI味】提示，以及 `dsh/agent-presets/qq-chat-v2/agent.cordis.yml` 的先读快照、选择性参与、主体性、分条与节奏。保留【反AI味】原标签与原文；没有移植其会话 token 参数，也没有移植另一个调度器。现有原生插件绑定仍负责当前聊天的权限与回合生命周期。

## 模型实际看见的内容

- 每个新窗口首次执行请求包含完整当前人设；后续请求不重复全文，人设变更时显式替换。运行时人设、记忆上下文、skills 注册和原生 tools 保持可用，不取消审批或扩大聊天权限。完整人设不再按 12,000 字硬截断。
- 普通消息投影保留时间、昵称、稳定人物代号 U、消息代号 M、文本、引用、@、媒体转写与附件关系。完整 QQ、sourceId、inboxSeq、协议版本与路由保存在宿主；工具参数先还原，再经过原有权限与证据校验。代号按聊天隔离、持久化，不是认证凭据。工具分页游标仍按真实展示范围返回。
- 新消息和 background/summary 分开；背景包含已经处理的消息和机器人真正发送成功的回复，不因已读而消失。启动前消息只用于记忆，不重新成为回复请求。读取背景不消费等待中的队列。
- 长期记忆仍按原规则由模型整理。短期滚动摘要采用有来源的原文摘录，保留人物、时间与更正原句，标注未核实/机器人曾说；不把猜测、玩笑或机器人的说法自动升级成用户事实。本版不声称具备自动语义合并、事实真伪判断或完整待办状态推断。

## 实际边界与持久化

近期视图最多 40 条、约 12,000 字符；单条投影可截短并标记，详情按工具分页查询。摘要最多 60 条且不超过 12,000 字符。0.19.1 起滑动只保存回执并推进本地窗口，不新建 DSH 会话；自动轮换恢复原有压缩、空闲与记忆回执条件。该预算不等于总模型 token 上限，固定人设、工具定义和工具结果仍额外占上下文。

0.19.1 起持续对话没有累计输入、累计发送或总时长上限；等待可继续，明确停止和连接失效仍取消工具。未展示消息保留，结束后交回现有调度。

`chat-context/<聊天哈希>/messages.private.jsonl` 保存完整消息快照与修订；`window.private.json` 保存代号映射及窗口；`receipts/` 保存每次滑动来源和摘要。先写回执再推进窗口；写入失败不删除原始窗口。长历史的完整文本继续保留在日志、记忆原始记录及旧 DSH 会话中，不保证全部同时注入模型。显式记忆重置会将此目录一并纳入可恢复备份，普通启动和升级不清除它。

## 记忆整理（0.22.1 已改为同一会话）

0.19 采用独立整理会话；0.22.1 按用户要求取消此分离。启动各批次整合、上线招呼和普通对话均使用当前人格的主会话，空闲整合也复用该会话。整合阶段只开放原有记忆工具；成功保存并取得回执后，才进入普通对话工具阶段。未知退出确认针对实际主会话；此前独立整理会话仍保留历史，不迁移或删除。详见 SAME-SESSION-0.22.1.md。

## 验证边界

新增窗口、来源代号、媒体、摘录回执失败、并发到达、会话轮换及整理退出确认回归。现有启动、引用失败、记忆来源、原生工具与持续对话回归继续运行。真实模型的接话自然程度需要实际群聊观察，不能用通过模拟测试代替。
