# 0.25.0 · 结构整理与 Web 面板更新

本版整理多次迭代积累的重复规则，修复原生会话重复重建，并更新本地管理面板。0.24 的角色模拟、同会话记忆整合、休眠和预约唤醒继续保留。

## 会话连续性与逻辑整理

- 启动、普通消息、自动轮换和手动新对话共用会话创建、权限设置、持久化命名与替换实现。新会话统一保存协议标记，避免手动或轮换后下一条输入再次创建会话。
- 会话创建失败保留当前会话与退休历史；创建中停止后不继续设置权限和提交输入。状态回滚后使用恢复的当前状态。
- 原生聊天、旧工具路径和内部记忆整合共用查询分派；后台读取不改变访问时间，维护先预览、随最终 digest 提交。
- 即时和延迟回复共用媒体、拍一拍与多气泡计划准备；公开发送仍经唯一出口，保留逐条回执和未知结果不重试的规则。
- `/ver` 使用统一版本来源。新增 [当前逻辑地图](ARCHITECTURE.md) 与 [重构记录](REFACTOR-2026-10.md)。

## Web 面板

- 浅色分组导航与 SVG 图标，统一标题、卡片、表单、按钮、提示、日志和确认弹窗。
- 语音能力摘要提前展示，预设库与配置区在宽屏并排；分别显示本地就绪、云端已配置和缺少组件。配置状态不等同真实调用验证。
- 服务状态与 QQ 接收状态分开显示；切换页面回到顶部。手机布局采用可滚动导航与单列表单。
- 登录提示页同步更新，说明书补充连接、聊天规则、人格与声音的上手步骤。

## 安装与更新

下载 `qq-bot-dsh-0.25.0-windows-portable.zip`，解压到新版本目录，按 [README](../README.md#下载与安装) 使用统一激活脚本更新。便携包包含服务 Node 依赖，不包含 Node.js、DSH、QQ/NapCat 或语音模型；源码 ZIP 不带依赖。服务与配套轻量插件必须一起更新。

更新前停止 QQ 接收并等待任务退出，沿用原部署根目录；配置、会话、记忆和旧版本继续保留。GitHub 发布不会自动更新现有安装或开启接收。

## 验证与限制

完整独立服务 359 项中 353 通过、6 项 SDK 条件跳过，随后安装版 DSH 单独补跑 6/6 通过。便携插件 102 项通过、1 项 Windows 符号链接权限条件跳过；原记忆核心自检通过。详情见 [VALIDATION.md](VALIDATION.md)。回归使用虚构资料、本机模拟接口和隔离的 SDK 对象；浏览器检查桌面、宽屏及手机布局。未调用真实模型、QQ 发送或 MiMo 音频接口。

超长对话的整理容量和持续聊天内存增长仍为待处理事项。本版没有通过截断原文、清空幂等信息或恢复累计调用上限掩盖这些问题。
