# 0.17 消息快照与人物记忆

本版参考 Derpyu520/qq-bridge 的二代逐条消息快照、未读背景与机器人自身份说明（对照提交 a56164e70a0521a7829138a42eee76066fde2b8b），在当前独立服务中重新实现。没有引入第二套 Agent 或调度器。没有沿用参考实现的入库原文截断。

## 输入结构

传给 DSH 的仍是一条执行请求：文本内容包含宿主说明及 JSON 消息快照，图片另作真实附件。快照内的成员不是 DSH system/user 角色；QQ 昵称、原文与历史资料不具有宿主权限。

```json
{
  "version": 2,
  "chat": {"type": "group", "id": "100000009"},
  "self": {"qq": "100000001", "nickname": "机器人", "card": ""},
  "trigger": {"kind": "ambient", "messageIds": ["1", "2"]},
  "messages": [
    {"sourceId": "100000001/group/100000009/1", "qqMessageId": "1", "sender": {"qq": "100000002", "nickname": "甲", "card": "甲的名片"}, "text": "我喜欢茶", "mentions": [], "replyTo": null, "media": []},
    {"sourceId": "100000001/group/100000009/2", "qqMessageId": "2", "sender": {"qq": "100000003", "nickname": "乙", "card": ""}, "text": "我喜欢咖啡", "mentions": [{"qq": "100000002"}], "replyTo": {"messageId": "1", "resolved": false}, "media": []}
  ],
  "context": [],
  "omitted": 0
}
```

- 每条消息保留原始发送者 QQ、昵称、群名片、QQ 时间、本机接收时间、消息 ID 和本地序号。身份以 QQ 为准：同名不合并，更名不换人。
- `text` 仅含该条消息自己的文字。`parts` 保留消息段顺序；`mentions` 是被 @ 者。`replyTo` 单独保存原消息作者、文字和媒体；获取失败保留未解析标记，不猜作者。
- `media` 带所属消息和作者；语音转写、图片附件名不会因后续另一人发言而换主人。`forwards` 的节点单独保留历史作者，未知 QQ 保持空值。
- 当前批次逐条准备媒体，再整体限制实际图片附件数量/总量。历史存储过的图片没有在本轮附加时，查询和快照标为 `stored_not_attached`，不能假装本轮看过。
- 群背景、插话、即时记忆和后台整理使用同一快照。新静态身份规则每会话更新一次；不每轮重新注入人设或整库。

## 原文与模型预算

接收到的原文及消息段完整写入本机索引；开启记忆时另有逐条原始记录和展开快照。群消息批次不再剪裁后伪装成最后一个人的消息。已获取的引用/转发原始返回也留作本地来源，模型视图不直接展开这些冗余数据。

模型输入和查询仍有视图预算；缩短时显式返回 `textTruncated` 和原始字符数。`qq_get_message_detail` 可按 `nextTextOffset` 继续读取长原文。未提供的背景消息保持未读。索引仍只保留最近 500 条，这与截断单条原文是两回事；记忆关闭时没有长期原始归档。历史版本已被截断的原文无法凭空恢复。

媒体读取仍保留目录隔离、大小与层级限制；超过展开限制会标记，不能把未解析内容当作已识别。

## 人物记忆

所有运行中的模型写入入口（原生记忆工具、旧协议、群工具、后台整理）提供实际消息证据。人物页采用 `user/<QQ>.md` 或 `user/<QQ>/主题.md`。

`write` 必须带 `subjects`；非人物事实用空数组。每个归属项包含人物 QQ、`basis`（self / reported / bot）和来源 ID。宿主校验来源存在、发送者身份与人物页归属，持久化人物、证据发送者和来源 ID，并在跨会话读取时提供人物归属摘要。

- 本人陈述：证据发送者必须是该人物 QQ。
- 他人转述：明确标记 reported；不能当作当事人已确认。
- 引用/转发混合消息：第一版保守地禁止标成 self，应标记 reported 或等待独立确认。
- 机器人身份：bot 只可对应当前登录机器人 QQ。
- 旧库缺少可靠身份记录的资料标为 `legacy_unverified`，不自动把“我/用户/他”归给当前发言人，不迁移、合并或重写旧人物页。

来源校验不能证明自然语言事实本身为真，也不能彻底消除模型理解错误；它阻止可结构化核验的串人和无来源写入，并保留可追溯证据。

## 发布与验证

服务与轻量插件必须一起更新。沿用原统一发送出口、工具结束回合、回执与沉默规则；未更改群聊参与、权限、允许名单和会话轮换策略。

本地测试覆盖长原文、同名/更名、多人缓冲、最后消息为纯文本时的前序语音、引用/@/转发作者区分、记忆转述归属、旧资料拒绝误归属、后台整理和跨会话回忆。具体检查结果见 `VALIDATION.md`。模拟与 SDK 回归不等同于真实模型理解或真实 QQ 联调。
