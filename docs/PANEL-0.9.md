# 面板 0.9

## 聊天选择与重置

“对方 QQ 或群号”改为按聊天类型筛选的下拉框，选择即加载。默认仅显示面板接收名单中的当前账号对象；可显式显示未接入及历史账号资料。打开记忆不会扩大接收范围，号码相同但机器人账号或聊天类型不同的资料不会合并。“已有资料”指已建立本机记忆库，不代表已经读取 QQ 客户端的完整聊天记录。

提供“重置此聊天全部记忆”和“重置当前机器人全部聊天记忆”。后者包括当前账号已经移出接收名单的资料，但不包含其他机器人账号。必须先停止机器人接收并等待消息、维护、语音及资料查询完成，面板再确认范围。

重置会将整个记忆目录（包括人设、原始来源、修订记录）和表情/黑话知识文件移动到私有运行目录 `memory-reset-backups/<编号>/`，保存 manifest 和旧桥接状态。移除对应活动及历史会话订阅，写入新的工作区代次；下一条消息创建新 DSH 会话和工作区，旧会话与旧工作区保持留存。QQ 客户端聊天记录、语音配置、名单、聊天策略、消息去重和每日主动额度不清除。

这不是永久删除或安全擦除。备份保留在本机，恢复目前需要维护者在停机后检查 manifest 并显式选择恢复内容，没有提供自动“撤销”按钮。进行中的重置有事务日志：启动时先回滚未完成的移动与桥接状态，再加载服务，避免半重置状态运行。路径限于运行目录并拒绝符号链接。

## 主动行为与提醒

- **定时搭话与追忆**：按照随机间隔、活动时段和尝试次数调度。私聊使用当前活跃聊天的记忆追忆；群聊读取近期群消息，模型可以不发言。
- **群消息触发接话**：收到未 @ 的群消息后，合并等待，再按冷却间隔判断是否接话。
- 两者共用聊天队列、任务取消和群发送限额。0.9 在定时候选生成前后都检查待合并群消息，优先处理新消息，避免同一时刻竞争。两者的“尝试次数”并非合并计数；发送限额是共用的。即使串行执行，也不能保证模型永远不重复话题。
- **接收 DSH 定时任务的完成结果**：监听属于本聊天的 DSH `schedule` 插件任务，将完成结果投递至原聊天；不创建任务、不回放离线历史，不等于自主搭话。

## 黑话与表情

黑话提案来自本群的处理回合，每次最多五条，必须引用本轮合法消息证据；相同词条不重复新增。候选在本机人工审核，只有 confirmed 状态才注入本群知识上下文。公开查证按用户点击发起，仅查询词语，不自动确认词义。不是修改模型权重，也不是跨群共享词典。

“收藏到 QQ”权限仅控制面板手动操作：验证当前账号与聊天策略后下载表情、验证图片，再调用 NapCat `add_custom_face`。结果进入机器人 QQ 账号的收藏表情，不会发给聊天对象，也不会自动收藏全部图片。该真实接口仍需在授权场景验收；不要把模拟测试当作真实 QQ 收藏成功。

## 语音安静模式

提供 scheduled（按时段）、always（全天不发语音）、never（关闭安静限制），分别可在私聊/群聊默认及独立聊天覆盖。默认 scheduled，保留原开始/结束小时。按北京时间判断跨午夜时段，开始与结束相同表示没有安静窗口。

安静模式优先于“适合时优先语音”；关闭限制不绕过语音发送权限和正文长度/内容限制，也不强制所有回复都使用语音。仅 scheduled 时显示小时设置。MiMo/本地服务和密钥仍统一配置。

本机媒体读取配置是 NapCat 返回本地文件路径时使用的目录白名单，ffmpeg 用于兼容格式转换；不是聊天记忆目录或下载目标。

## 日志与说明书

运行日志记录本独立服务启动/停止、面板操作结果、QQ 连接、消息接收/投递、Agent 回合、后台记忆整理。结构化事件只接受固定名称、模块、操作路径及耗时/计数，不写入消息正文、音频、密钥、登录 URL 或上游错误原文。详细连接错误仍在连接状态显示。

日志保存在 `.runtime/logs/system.jsonl`，按约 1 MiB 轮转，当前文件加三个历史文件；页面可按模块/级别筛选最近 300 条，并每五秒自动刷新。只读 API 需要面板认证。日志持久化不代表进程被强制结束时一定能记录停止事件；不会补录升级之前的事件，也不汇总外部 QQ/NapCat/DSH 的内部输出。

“说明书”页面仅占位，没有加入使用说明正文。
