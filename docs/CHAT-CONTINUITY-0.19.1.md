# 0.19.1 聊天连续性

0.19.0 将精简投影的 8 次请求/20,000 字符/60 条输入阈值用于新建 DSH 会话，且持续执行首包超过12,000字符便不能继续等待。这些阈值已移除。滑动窗口仍按聊天持久保存原文、稳定人物/消息代号、近期原文和带来源摘录，但其滑动不再新建 DSH 会话。投影升级也在原会话完成。

自动新会话仅沿用原有生命周期：当前聊天启用轮换、成功压缩次数达到该聊天有效设置、空闲达到有效设置、记忆整理回执有效、无新消息和活动任务。既有设置不改；不恢复旧默认值覆盖用户配置。手动新建、预设切换、真实中断恢复仍走原机制。

持续聊天取消总时长、累计输入、累计发送、原生回调及普通消息查询总次数限制。单次工具参数、QQ发送权限/频率、停止和断联检测仍有效；工具授权仍由心跳续期，不将授权失效视为正常轮换。单次等待1～300秒，超时可以再次等待，不限制整段对话。

`qq_wait_for_messages` 新增 `purpose` 和 `quietSeconds`：

- `reply`：按最后一条来信补足10秒静默，期间的新消息重新计时，直到静默满足或最长等待到期；返回 `quiet`，预算到期不等于对方说完。阅读和思考消耗的时间也计入。
- `messages`（默认）：新消息/当前子任务通知立即返回，否则按倒计时结束。回复后先等30秒，准备收尾时观察300秒，明确告别除外。超时不强制发言；有新消息也无需每条都回。

聊天提示使用 qq-bridge 二代原文的六段社交/表达规则，保留【反AI味】标记；等待规则按本项目秒单位适配，无会话令牌。旧会话通过策略版本更新收到新规则，无需为了更新提示新建会话。人设、记忆技能和工具授权保留。

本地持久化不是模型理解质量的保证；摘要仍是有归属的原文摘录，并非完整语义总结。既有 DSH 会话保留此前输入，首次进入新会话才补齐最近消息与摘要。真实表达效果须通过后续真实模型对话验证。
