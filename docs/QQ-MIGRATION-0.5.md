# QQ 功能迁移 · 0.5

本版是五类旧插件能力的第一批迁移，并参考 qq-bridge a56164e 的表情认知和黑话候选机制增加隔离知识库。独立服务仍依赖 DSH。只更新源码和本地模拟验证，没有部署到正在运行的 QQ 服务。

## 已实现

| 范围 | 本版行为 |
| --- | --- |
| 引用与消息 | CQ 字符串及数组；引用先验证所属聊天，再展开历史资料；群聊引用机器人消息可触发回复，引用其他成员不会自动视为 @；face、JSON/XML 分享卡片、消息段 poke；可选文件/视频附件保存与当前聊天发送 |
| QQ 控制 | 管理员白名单；/help、/ver、/status、/id、/doctor、/memory、/workspace、/preset、/session 查询；/new、/stop、/steer 操作。停止会取消运行并废弃排队消息，附件读取期间停止也不再启动模型 |
| 原闹钟投递 | 持续订阅本服务拥有的 DSH 当前会话及可确认后端归属的已轮换会话；仅接受真实 schedule 插件来源、成功完成的回合，按会话与回合去重后向原聊天投递文字 |
| 群聊自主参与 | 开关启用后合并未 @ 的群消息；默认等待10秒，每5分钟至多一次判断，20条/12000字；模型可保持安静，发送受公共群限流控制，判断间隔持久化 |
| 群聊专用工具 | 公开关键词搜索、带来源的本群记忆读写、本群工作区 md/txt 读写和图片读取/发送；禁止跨聊天、隐藏目录和路径越界；文件写入至多3次，搜索至多1次；模型输出 actions，宿主校验执行后再提交结果给 DSH |
| 人设与记忆面板 | 按聊天编辑 SOUL 人设、记忆页新增/改写/忘记、查看关系及健康检查；保存前检查版本，运行中的聊天拒绝编辑；保留旧人设与记忆修订 |
| 表情学习 | 收到带表情标记且含公开 URL 的图片可进入本聊天知识库；导入 QQ 收藏；读取图片后可写含义、标签并按需准备回复；面板可编辑笔记和显式收藏到 QQ |
| 黑话学习 | 模型根据本轮真实来源提交候选；只加载人工确认的含义；面板编辑、确认、否决、公开查证并保留来源；候选不能自行升级为确认 |

## 默认值与权限

新添的文件收发、群聊自主参与、群聊专用工具、知识学习、闹钟转发默认均关闭。管理员名单为空，QQ 命令默认不可用。配置保存仍要求先停止连接。普通群聊默认需 @，开启自主参与后才旁听允许群。

群聊工具是独立服务的受限操作层，DSH 自身工具权限仍由群专用预设配置；本服务不会自动扩大 DSH 权限。模型提议的表情发送仍经过媒体验证和当前聊天投递，不能把账号级收藏接口当作跨联系人资料查询。

知识库保存在私有 .runtime/knowledge/ 下，按机器人、聊天类型、对象哈希隔离。QQ 收藏本身属于账号，导入动作只给所选聊天建立笔记副本，不自动向所有群共享。图片 URL 可能过期；无法获取时报告失败，不假装已看过。公开搜索只发送关键词，来源作为不可信资料；本轮未做外网搜索服务验收。

## 协议

普通输出保持 reply/memory。可选 qq.replyTo 是本聊天数字消息 ID；qq.file / qq.video 是当前工作区或本轮附件路径，单文件上限8MiB。二进制视频只保存附件，不代表视频语义识别。多媒体每轮只选择一种形式。

工具请求：

```json
{"reply":"","memory":[],"actions":[{"tool":"qq_group_web_search","args":{"query":"公开关键词"}}]}
```

最多4个工具轮次，每次最多4项操作。后台主动搭话和闹钟输出不能执行这些操作或写记忆。表情工具为 qq_list_stickers、qq_get_sticker_image、qq_sticker_note、qq_send_sticker；黑话工具为 qq_slang_query、qq_slang_submit。group 前缀工具只对群开放。

## 与原版仍有差异

- QQ 命令尚未迁入模型切换、工作区/预设切换、切回历史会话、retry、ocr 快捷命令、输出模式、plan、permission、goal 和诊断包导出。当前同名 /workspace、/preset、/session 只查询，不声称全套命令等价。
- 闹钟仍在 DSH 中创建和管理；这里迁移投递，不包含 cron 编辑器。无法自动识别旧插件所有会话与目标 QQ 的映射，因此不会订阅其他插件、其他聊天或缺少后端归属的旧退休会话。需要后续显式映射导入。断线期间不补发；订阅恢复只处理之后的新回合。混入普通用户消息的回合不作为闹钟投递，避免把对话内容误转发。
- 新群聊流程复用旧路径、图片和搜索校验，采用有界结构化工具回合；未把原插件全部 Cordis 生命周期、关系策略和任务调度器原样搬入。定时群聊与实时自主参与是两个开关。
- 卡片只提取有界内容，不执行链接/脚本；没有通用 QQ 管理 API、群成员管理或撤回工具。notice 类型戳一戳尚未接入，仅支持 message 内的 poke 段。
- 人设界面是独立面板的新实现；原自动 Git 提交、Cordis 事件和原插件完整可视化布局未迁入。关系图当前为可点击页面与关系列表。
- 黑话为候选审核流程，没有自动搜索后自动确认。QQ 收藏导入/收藏接口因 OneBot 实现而异，真实接口与图片 URL 有效期仍待授权联调。不会自动批量收藏群图片。

## 验证

56 项 standalone 模拟测试通过；原记忆 CLI 自检通过。浏览器使用虚构聊天完成：人设保存、新建记忆页、黑话确认、刷新后保持、点击关系页跳转编辑。未连接真实 QQ，也未调用真实收藏接口、外网查证或真实闹钟。正式运行目录与桌面 QQ 接入保持原状。
