# 记忆预算与上下文估算

启动资料预算与相关记忆页预算统一标为“字符数”，取消原先每项 30,000 的固定上限。全局配置、私聊/群聊默认和单个聊天覆盖均支持更大的值；仍须为至少 1,000 的 JavaScript 安全整数，以免数值被静默舍入。原有预算不会自动改变。

面板按两项预算合计，以约 1～4 字符/token 粗估输入占用。这不是分词器测量，也不是完整请求大小；不同语言、表情及模型可能超出估算区间。资料不足不会填满预算，选页、单页截取规则保持不变；其他系统指令、聊天历史、工具结果和回复空间需要另行预留。

可在估算区填写模型上下文容量，显示参考占比；高值超过容量或达到 80% 时提醒。容量留空时无法判断实际超窗，单项超过原 30,000 建议值仅显示大预算提示。所有提示都不阻止保存。参考容量仅为当前页面计算器输入，不会保存为聊天配置，也不会修改模型设置。

新会话仍按原有规则加载资料；改变预算不会向已有对话重新注入全部记忆。字符数沿用字符串长度计数，部分表情可能占多个计数单位。原记忆核心不变。
