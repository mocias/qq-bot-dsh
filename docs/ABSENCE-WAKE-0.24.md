# 0.24 用户离开、原会话定时唤醒与人格记忆导出

## 用户离开

`userAwaySeconds` 默认1800秒，可在“会话与聊天”修改并按聊天覆盖。宿主维护最后一条真人来信时间，私聊按对方，群聊按群成员来信。机器人发言、工具调用、角色模拟、定时唤醒都不重置这个值；不使用等待迭代次数。

等待超出阈值返回 `reason=user-away`，停止普通等待和公开发送。模型先保存未完成的角色状态，再通过 `qq_handoff` 写详细交接。交接成功才结束聊天执行，随后宿主在原DSH会话切换记忆工具，取得 `qq_memory_digest` 保存回执后进入休眠。整理期间来信持久化排队；交接或整理中断可在确认旧执行退出后继续，同一会话不替换。手动停止仍优先。

用户回来时，在同一会话提交完整人设、最近交接摘要、未完成事项与新消息，记忆由现有运行时上下文注入。无上线招呼，无历史补发。长期记忆关闭时仍交接休眠，但不声称已经整理记忆。

## 定时唤醒可以主动发送

模型可以使用当前DSH实际开放的 `schedule_create` 等工具，为自己预约。QQ面板的“允许 DSH 定时唤醒并主动发消息”以及对应接收开关均需开启。

安装版DSH 0.2.1-rc.2的schedule服务到期后先 `resolveAgent`，再投递来源为 `schedule` 的消息。QQ原生插件仅拦截已登记QQ会话的该类投递，先持久化到本地唤醒队列，由QQ服务恢复同一会话的原生工具、当前人格和记忆后提交模型。活动会话则投递到当前等待收件箱；父模型等待子任务时提示其读取。不是先裸跑模型，也不把普通DSH正文当作QQ回复。

每个预约发生时刻独立去重，周期批次拆分重投也不会重复。发送仍经过统一出口、当前聊天权限和实际回执；未知结果不自动重试。切换人格、停止接收、旧后端、过期服务代次的提醒不补发。服务需运行；此能力不启动关闭的DSH/QQ进程。DSH自身的预约投递记录表示提醒已交给持久化队列，不等同QQ发送成功；QQ发送以发送工具回执为准。

预约不重置用户离开计时。模型可以主动发送具体内容，随后再次检查等待：用户仍离开时交接整理并继续休眠。规则允许真实世界模拟期间自然主动发言，也允许使用当前实际开放的其他DSH工具。

## 语音与导出

- `qq_send_media` 新增 `voiceStyle`：最多300字的语气、情绪、语速及停顿意图，与实际朗读的 `voice` 正文分离。MiMo合成请求会收到此说明；本地Windows语音不具备相同的逐条情绪控制。不会改变保存的音色配置，不保证实际情绪效果。
- 提示词页新增8项，现共98项，继续全局默认＋人格覆盖；现有用户覆盖不会被升级覆盖。
- “人设与记忆”选择聊天和人格后可一键下载ZIP。包括该人格的人设、记忆Markdown、归档Markdown和交接摘要；不含其他人格、密钥、原始DSH日志。导出只读，不切换当前人格。最大64MiB、16000文件。

## 发布与验证边界

本版修改稳定原生加载入口，并兼容已加载旧入口暴露的发布清单路径。统一激活后必须确认 `probe.scheduledWakeRouter=true`；不能只看版本号。保持人工停止状态；不为验收启动真实模型或向QQ发送。

已用隔离临时资料测试离开交接→原会话记忆回执→休眠→原会话恢复，预约→工具恢复→一次QQ模拟发送→再次交接，交接中断恢复，以及权限隔离、下载和语音请求。安装版DSH SDK实际定时器和原生工具测试通过；浏览器完成ZIP下载，Windows标准ZIP读取通过。真实模型的自主选择和MiMo声音效果仍需实际使用观察。
# 2026-10-22 更新：整理后恢复循环

最新用户契约取代下文“成功整理后休眠”：启动整理、离开交接整理及普通后台整理成功后，设置持久化循环恢复标记，经原聊天队列在同一会话恢复QQ工具并先等待消息，再按60秒时钟执行角色模拟、保存状态、按需动作和继续等待。停止接收、整理失败、旧执行退出未确认时不得恢复；待处理真人消息优先。

记录本次整理已经处理的最后真人来信时间，不改写真人时间。没有更新的真人来信时不再次触发相同的离开交接；新消息到来后重新计时。等待工具阻塞期间不连续调用模型；定时模拟需要模型处理，模拟验证不证明真实模型的长期表现。

定时主动搭话每日次数0表示关闭，面板明确标注。升级不把0转换成无限额度。遗留休眠会话可按已启用主动策略、时段、间隔和额度执行一次后台尝试，继续保持旧休眠状态；成功启动整理后进入新循环。后台尝试先预留额度，沉默和失败也占额度，未知发送不重放。每日额度只管定时搭话调度，不管普通聊天或循环内由模型选择的表达。
