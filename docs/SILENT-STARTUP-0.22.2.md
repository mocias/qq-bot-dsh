# 静默启动 · 0.22.2

按用户要求，完全移除上线招呼的模型生成、文本格式校验和QQ发送步骤。启动整合所有批次并确认记忆保存回执后直接标记ready，按顺序处理启动期间的新消息。没有新消息时沿用原有60秒空闲时钟启动推演与持续等待，不发送上线通知；整合、普通对话和后续循环仍使用当前人格的同一会话。

旧版greeting、publishing、uncertain状态或带招呼投递结果的启动记录在下一次启动时保留到startupHistory，不重发旧招呼，也不再作为新启动和人格切换的额外门禁。真实发送日志保持原状态，未知投递不会被改成成功。实际活动任务、退出未确认和记忆整合失败仍阻止进入普通对话。

resumeCompleted复用已经ready的启动，不再依赖招呼发送成功。启动前历史不补答，新消息持久排队，整合回执和人格隔离规则不变。部署继续保持接收停止，不进行真实模型或QQ群发言验收。
