# 0.18.0 · 持续对话与完整记忆流程

合并两项开发更新，服务和配套轻量 DSH 插件统一为0.18.0。

- 正式原生聊天统一使用持续对话，不再保留旧模式开关。发送工具即时返回实际投递回执，普通正文不重复发送。关闭历史消息查询不会关闭接收、发送或等待。
- 模型可自行选择1～300秒等待，用户消息和本窗口子任务通知可提前唤醒；结果先交主智能体处理。活动窗口最长15分钟，不保证跨停止或重启恢复。
- 私聊和群聊统一支持记忆读写、全文搜索、元数据筛选、运行时上下文及独立人设管理，保留人物QQ归属、来源与完整原文。
- 压缩后空闲、累积完成对话后空闲和久未写入提醒共用一个维护调度。默认累积3轮，空闲时间沿用原设置；不因此提前轮换会话。
- 降级归档按原版由模型判断，180/90天为建议；新增索引编辑、摘要回填、带逐字原文依据的语义精简/合并和严格诊断。Git实现保持现状，旧全文留存。

## 下载与升级

- `qq-bot-dsh-0.18.0-windows-portable.zip`：服务、轻量插件、启动/更新脚本和Node依赖。
- `qq-bot-dsh-0.18.0-source.zip`：源码，不含Node依赖。
- `SHA256SUMS.txt`：两个压缩包的SHA-256校验值。

仍需外部安装 Node.js 22+、DSH 和 QQ/NapCat；不是包含全部环境的EXE。安装包不含账号、密钥、聊天记录、记忆、录音或语音模型。

将新包解压到独立版本目录，沿用原部署根目录，通过 `scripts/activate-release.mjs` 统一更新并重新打开面板。已有配置、会话和私人记忆保留；QQ接收默认停止，由用户核对后启动。具体命令见根 README，不能单独替换轻量插件文件。
