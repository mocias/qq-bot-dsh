# 同一会话内先整合再聊天 · 0.22.1

启动流程沿用当前聊天、人格的DSH会话ID，按顺序执行所有记忆整合批次、上线招呼、普通对话。空闲整合也复用该会话，不再创建或命名额外的“内部记忆整理”会话。

整合阶段仍是有限维护回合，只开放查询、诊断、维护预览和最终提交；qq_memory_digest成功落盘且取得回执后才进入下一阶段。普通对话阶段重新绑定聊天工具并继续qq_wait_for_messages循环。通过明确阶段提示区分历史维护规则和本轮权限，避免同会话内遗留的“只整理不聊天”或持续等待指令互相冲突。整理资料和结果保留在此会话上下文，仍受DSH正常压缩机制管理。

整合期间新消息持久排队，不取消整合，不并发开启同一会话普通回合；保存失败不能发送上线招呼或放行新消息。明确停止仍有效；退出未确认时检查实际主会话，不创建替代会话越过确认。旧独立整理会话及真实记忆、历史、人格分隔完整保留。

本次没有把多个聊天或人格合为一个会话，没有改动正常会话恢复、显式新建会话与历史轮换规则。持续普通对话仍由0.22.0同回合续接机制负责。部署保持QQ接收停止；隔离测试不能代替真实模型运行验收。
