# 0.7 聊天域配置与记忆管理

## 配置范围

在“会话与聊天”先选择私聊默认、群聊默认，或某个已配置的好友/群。指定对象逐字段勾选“单独设置”；未勾选的字段随对应默认值变化。清除覆盖恢复继承，不删除人设、记忆或会话。

覆盖标识为 `机器人账号/private或group/对象号码`，换账号后不会套用其他机器人的覆盖。可选对象来自“连接与配置”的允许名单；覆盖设置不能扩大接收范围。修改前需停止 QQ 连接并等待活动任务结束。

| 分类 | 规则 |
|---|---|
| 连接与配置 | DSH/OneBot 地址、访问凭据、机器人与允许名单、桌面 QQ、本机媒体目录 |
| 语音与通话 | 本地或 MiMo 服务、密钥和音色共用；是否接收/回复语音按聊天域决定 |
| 会话与记忆 | DSH 预设、排队/插话、长期记忆、压缩后空闲整理；自动轮换目前仅用于私聊 |
| 消息功能 | 图片、合并转发、文件与视频分别设置接收/发送，语音识别与回复独立设置 |
| 表情与黑话 | 表情学习、选择已存表情发送、面板收藏到 QQ 分开；黑话学习仅群聊 |
| 主动参与 | 默认关闭；间隔、时段、额度按聊天配置，仍使用原有持久化调度器 |
| 群聊参与 | 未 @ 参与、合并等待、发送频率和群专用工具 |
| 控制与提醒 | 管理员名单与本聊天的 DSH 闹钟投递 |

群聊语音由原先固定禁用改为可配置，升级时仍默认关闭。发送表情需要同时允许图片发送；学习收到的图片需要允许图片接收。关闭长期记忆后不注入或记录新的长期记忆/压缩摘要，已存记忆仍可在本机面板管理；已有 DSH 会话上下文不会因此被擦除。

旧平铺配置保留为升级基线，`chatPolicy.private/group/overrides` 保存覆盖。专用接口检查版本，拒绝陈旧页面覆盖新配置。密钥不出现在聊天域响应中。每个范围的未保存草稿独立保留，保存冲突时需重新加载。

预设决定 DSH 的模型与工具权限；独立服务的消息功能开关约束本服务处理的媒体和宿主工具，不代替 DSH 自身的工具审批。变更预设会使用该预设对应的工作区/会话；普通新会话与自动轮换保留原工作区和长期记忆。

## 连接字段说明

- DSH 服务地址是独立运行的 DSH 后端地址，并非模型 API 地址。
- “使用本机 DSH 登录状态”从本机已有登录取得授权；不启用时填写 DSH 启动链接中的令牌。
- QQ 访问令牌是 NapCat/OneBot WebSocket 配置的 `access_token`，两端须一致；它不是 QQ 密码或 MiMo 密钥。
- DSH 预设移至聊天域设置，允许分别配置私聊、群聊和指定对象。

## 记忆迁移边界

“人设与记忆”只保留一个聊天选择器。加载后统一显示记忆状态、人设、记忆页、关系、健康检查和表情资料；群聊另显示黑话。新会话按钮仍要求 QQ 连接且聊天空闲。

| 原模块能力 | 当前实现 |
|---|---|
| Markdown 目录、boot、页面索引、访问记录、健康检查、关系数据 | 复用原核心，来源校验见 `legacy-memory/provenance.json` |
| 会话前记忆注入、相关页选择、写入与忘记 | 独立宿主适配；模型提交结构化提案，宿主校验来源、路径、版本后写入 |
| 空闲整理与私聊轮换 | 独立服务订阅成功压缩事件，整理取得持久化回执后轮换 |
| 原 CLI 与记忆技能 | 复用，CLI 只适配导入路径 |
| 自动 Git 提交、完整交互关系图、Cordis 事件挂载 | 未原样迁入；宿主保留修订备份，面板目前提供页面列表与关系边 |
| 原铸魂自动写入流程 | 未完整迁入；管理者通过面板编辑人设，模型不能自行改写 SOUL |

这是原记忆核心的独立进程适配，不能称为原插件全部功能无差别迁移。所有记忆仍按机器人、私聊/群聊、对象隔离；功能默认值继承不会合并资料库。
