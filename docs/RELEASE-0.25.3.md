# 0.25.3：删除工作区后新建，并补全人设命名

用户删除工作区表示结束该工作区，下一次启动聊天或准备消息时应创建新工作区及新会话。0.25.1/0.25.2 的原路径补建、旧会话关联恢复策略由本版取代。

- 受管目录、DSH 登记、成员关系或会话缺失时，新建不同路径的工作区及新 DSH 会话。检查接口只读，不重新创建或关联旧工作区；临时连接错误只报错，不当作删除。
- 已分配的新路径、新会话 ID 和命名编号持久化；失败重试沿用已预留结果。旧会话保留历史，配置、独立人格记忆和回执继续保留，不复制被删文件。
- 工作区：机器人 QQ / 私聊或群聊 / 北京日期-聊天类型-对象 QQ-所选人设卡名称。碰撞追加 `-工作区2` 等序号。
- 会话：北京日期-聊天类型-对象 QQ-所选人设卡名称-会话序号。人设名称来自当前选中的人格卡显示名，默认卡未重命名时显示“默认人格”；不会从提示词正文猜测姓名。
- 提交前发生删除时拒绝旧目录的模型请求并保留输入，在下一次会话准备时完成新建。外部路径缺失、文件或链接占用仍报错。
- 保留 0.25.2 的受限记忆格式修复；本版不更改用户最新上下文配置，也不将上下文溢出列为已修复。

服务与原生插件统一更新。升级前备份配置、记忆、桥接记录及 DSH 配置；更新保持停止接收，不自动执行模型或发送 QQ。已有名称作为历史保留，当前需要切换的聊天创建带人设的新工作区与新会话，不批量改名所有旧记录。验证见 [VALIDATION.md](VALIDATION.md)。
