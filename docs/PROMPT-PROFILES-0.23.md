# 0.23.0 提示词配置与工作区名称

面板新增“提示词配置”。90 个 QQ 提示词条目按聊天表达、对话输入、等待与模拟、主动搭话、发送与续接、委派与交接、工具说明及参数说明列出。默认文本保持原行为；本版本不改写默认分条节奏，也不改变主动任务调度。

## 编辑范围

- 全局默认覆盖内置文本；每张人格卡可再单独覆盖。未覆盖项继承全局，全局未覆盖项使用内置文本。
- 可搜索、查看条目来源及使用阶段、查看继承内容和完整清单、逐项或全部恢复继承。空字符串是明确的空内容，不是恢复继承。
- 切换条目、人格或面板页面保留本页草稿；保存仅保存当前范围。刷新/离开有未保存草稿时由浏览器提示。重新加载可放弃当前范围草稿。
- 保存使用修订号防止旧页面覆盖新配置，每次写入前保存完整旧配置备份。数据在私有运行目录 `prompt-profiles.private.json` 和 `prompt-backups/`，不进入发布包。
- 全局编辑要求所有接收停止；当前使用人格要求对应类型停止并确认任务退出。保存后下次执行采用新规则，沿用已有会话；更新后的完整规则重新注入，工具描述也使用同一份配置快照。

## 完整输入的组成与边界

1. DSH 系统、预设、审批、已授权工具和工作区上下文由 DSH 管理，本页面标出来源，不复制为 QQ 自定义规则。
2. QQ 固定提示词在本页编辑：包括初始/后续聊天、等待返回、定时模拟、状态保存提醒、发送成功、未发送纠正、结束续接与压缩交接。
3. 人设正文仍在人设与记忆页面按人格编辑。
4. 长期记忆正文、记忆维护专用规则及记忆/人设工具由记忆模块管理，不纳入此页，也不为展示此页读取私人记忆。
5. 当前时间、消息、引用、图片、人物代号、模拟编号、工具回执和历史交接记录为动态数据。模板修改不会伪造或修改这些事实。

用户可以修改提示文字，但不能由此扩大工具权限、绕过发送校验、改接收对象或解除必须保存角色状态的程序检查。每项最多 40000 字符，配置合计最多 600000 字符；这些是保存限制，不承诺模型有相应上下文容量。修改后的文本是否被模型完全遵循仍取决于模型及更高层指令。

## 工作区名称

新建目录使用 `北京时间日期-群聊或私聊-对象号码-人格卡名称`，例如 `2026-10-21-群聊-100000002-知遥`。默认人格卡也可在“人设与记忆”单独修改名称。名称采用明确的卡片名称，不从人设正文推断人物姓名。

已有工作区路径、会话绑定和记忆位置保持原样；修改人格名不会自动移动已有目录。非法路径字符替换为下划线，目录中的人格名称最多 40 个 Unicode 字符，重名使用独立重建父目录。DSH 历史会话标题仍按原会话规则保留。
